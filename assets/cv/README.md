# Youngkwon Ko - CV

The editable source is `youngkwon-ko-cv.tex`. Compile twice with XeLaTeX:

```sh
xelatex youngkwon-ko-cv.tex
xelatex youngkwon-ko-cv.tex
```

The design matches the portfolio: warm paper (#F8F7F3), charcoal text, muted green, thin rules, serif headings and sans-serif text. TeX Gyre fonts are preferred; Latin Modern Sans and URW P052 are used when needed, with a Latin Modern Roman fallback.

The two-page English CV follows the current portfolio and supplied CV. Creai+it ends in December 2025. Navy service is ongoing with an expected completion in August 2027. The third study is identified as a research manuscript because a publication venue was not supplied.

`page-1.webp` and `page-2.webp` are lossless 180-DPI renders of the compiled PDF. Update these images and `manifest.js` after editing the source. The site previews these exact pages at `#about/cv`, including page navigation and contained zoom. PDF and LaTeX downloads use the original files.

LaTeX auxiliary files and intermediate PNGs are not shipped with the site.
